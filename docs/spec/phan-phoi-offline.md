# Spec: Phân phối và bản offline (Distribution and offline build)

Status: v1.8.5 (2026-11-04). `index-offline.html`, `dist/MinhLee.app`, and `dist/netlify/index.html` are rebuilt from the v1.8.5 `index.html` and are byte-identical; the app's Info.plist reads 1.8.5 (§8).

**Out of date since v2.0.0-alpha (2026-11-04):** `index.html` now has a second importmap entry (`@supabase/supabase-js`), and `index-offline.html` and `dist/` were not rebuilt on purpose (owner's decision). `tools/build-offline.py` may fail on the two-entry importmap and is not checked. The offline copy and the Mac app do not include sign-in or cloud save. See `docs/spec/nhieu-nguoi-choi.md` §9 and `docs/tasks.md`.

## 1. Goal

Let the game be shared and played with no internet connection and no web hosting: by file, USB stick, or intranet share. `index.html` (CDN) stays the primary source. `index-offline.html` is a generated copy for offline use.

## 2. Files

| File | Role | How it is made |
|---|---|---|
| `index.html` | The game. Loads Three.js 0.160.0 from the jsDelivr CDN via an import map. Edited by hand. | Hand-written |
| `index-offline.html` | The same game with Three.js inlined in the import map (~1.1 MB). Do not edit by hand. | Generated by `tools/build-offline.py` |
| `tools/build-offline.py` | Generator. Python 3 standard library only | Hand-written |
| `tools/three.module.min.js` | Cached copy of the Three.js 0.160.0 minified ES module (~670 KB, MIT, no imports) | Downloaded on first run of the script |

## 3. Build

Command, from the project root:

```
python3 tools/build-offline.py
```

Steps:

1. Read `index.html` and find the importmap line `{"imports":{"three":"https://cdn.jsdelivr.net/npm/three@<version>/build/three.module.js"}}`. If it is not found, the script exits with an error.
2. If `tools/three.module.min.js` is missing (or looks invalid: under 100 KB and no `REVISION` string), download `three@<version>/build/three.module.min.js` from jsDelivr. Network is needed for this step only.
3. Base64-encode the library and build a `data:text/javascript;base64,...` URL.
4. Replace the importmap with one that maps `three` to the data URL. Add an HTML comment above it naming Three.js 0.160.0 and its MIT license.
5. Write `index-offline.html`.

Rule: re-run the script after every edit to `index.html`, so the two files stay in sync. No automated check enforces this (see `docs/tasks.md`).

Difference between the files (checked 2026-11-04 with a read-only diff): one replaced importmap line and one added comment line. All game code is identical.

## 4. Behavior

- `index-offline.html` makes no network request. The library is read from the importmap as a data URL.
- Gameplay, UI, and text are the same as `index.html`, because the game code is the same.
- The Three.js license header (`@license`, "Copyright 2010-2023 Three.js Authors", `SPDX-License-Identifier: MIT`) stays at the top of the inlined library. The importmap comment also names the version and license.
- Save data uses the same key as `index.html` (`mot-ngay-o-cong-ty.v1`). Whether the two files share saves in one browser is not tested (see §6).

## 5. Constraints

| Area | Constraint |
|---|---|
| Size | `index-offline.html` is about 1.1 MB, one file. |
| Browsers | Import maps and ES modules are required: Safari 16.4+, Chrome 89+, Firefox 108+, Edge 89+. Browser checks, in-app browser banner, and fallbacks: `docs/spec/tuong-thich-trinh-duyet.md`. |
| Version | Three.js version is read from `index.html`. Changing the CDN version there and re-running the script updates the offline file. |
| Tooling | Build needs Python 3 and network once (for the first library download). Gameplay needs no tooling. |

## 8. macOS app (v1.6.0)

### 8.1 Goal

Give Mac users the game as an app icon and window, with no browser. The app wraps the offline build, so it needs no network. Windows is not covered.

### 8.2 Files

| File | Role | How it is made |
|---|---|---|
| `tools/macapp/main.swift` | App source: one Cocoa window with `WKWebView`, menus, load-failure alert, `--selftest` | Hand-written |
| `tools/macapp/Info.plist` | Bundle metadata: bundle id `com.minhlee.mot-ngay-o-cong-ty`, `CFBundleShortVersionString` 1.8.5 (since v1.8.5), `LSMinimumSystemVersion` 11.0, display name "Một Ngày Ở MinhLee" | Hand-written |
| `tools/macapp/AppIcon.icns` | App icon (about 1.2 MB) | Committed |
| `tools/build-mac-app.sh` | Build script (steps in §8.3) | Hand-written |
| `dist/MinhLee.app` | Output bundle. `Contents/Resources/index.html` is a copy of `index-offline.html` | Generated |
| `dist/MinhLee-mac.zip` | Output archive, the file to send (1,587,223 bytes at the v1.8.5 build, 2026-11-04 14:56; 1,586,521 at v1.7.0; 1,583,693 for v1.6.1; 1,583,593 for v1.6.0) | Generated with `ditto` |
| `dist/.build/` | Intermediate per-architecture binaries. Not for sharing | Generated |

### 8.3 Build

Command, from the project root, on a Mac with Xcode Command Line Tools:

```
tools/build-mac-app.sh
```

Steps:

1. Run `tools/build-offline.py` (refreshes `index-offline.html`).
2. Compile `main.swift` with `swiftc -O -swift-version 5` for `arm64` and `x86_64`, target `apple-macos11.0`.
3. Join the two binaries with `lipo -create` into `Contents/MacOS/MinhLee`. Copy `Info.plist`, `AppIcon.icns`, and `index-offline.html` (as `index.html`) into the bundle.
4. Sign ad-hoc with `codesign --force --deep -s -`. No Apple Developer account is used.
5. Zip with `ditto -c -k --keepParent` to `dist/MinhLee-mac.zip`.

Rule: rerun the script after every edit to `index.html`. The app holds its own copy and does not read the file from the project.

### 8.4 Behavior

- Window: title "Một Ngày Ở MinhLee", 520 × 900 pt by default, minimum 360 × 560 pt. Frame is remembered (autosave name `MinhLeeMain`).
- Loads `index.html` from the app's `Contents/Resources` with `loadFileURL`, with read access to that folder only.
- Menus: app (Ẩn, Thoát ⌘Q); Chỉnh sửa (Cắt ⌘X, Sao chép ⌘C, Dán ⌘V, Chọn tất cả ⌘A), so the name field accepts paste; Hiển thị (Toàn màn hình ⌃⌘F, Tải lại game ⌘R).
- Closing the window quits the app.
- Load failure (missing file, or a navigation error): a Vietnamese alert, "Có chút trục trặc", with a friendly message. The app then quits. Raw errors go to the debug log only.
- If the web content process crashes, the page reloads.
- Media playback is allowed without a user gesture (`mediaTypesRequiringUserActionForPlayback = []`). Whether audio actually plays is not verified (§8.6, and `docs/tasks.md`).
- `--selftest`: after load, the app checks the page (`__gameReady`, start button, localStorage write and whether a marker from the previous launch exists, WebGL), clicks "Bắt đầu ngày mới", waits 3 seconds, prints `PHASE1` and `PHASE2` JSON lines, and exits.

### 8.5 Constraints

| Area | Constraint |
|---|---|
| Platform | macOS only. No Windows build (see `docs/tasks.md`) |
| Minimum OS | macOS 11.0 (`LSMinimumSystemVersion`). Tested on macOS 27 only |
| Architectures | One universal binary, arm64 and x86_64. Only arm64 was run |
| Signing | Ad-hoc, not notarized. Gatekeeper warns on other Macs. Steps in `docs/deploy.md` option 4 |
| Save data | Kept in the app's own WebKit storage, separate from browsers |
| Freshness | The app contains the `index-offline.html` from build time. Rebuild after every `index.html` change |
| Size | Zip about 1.5 MB |
